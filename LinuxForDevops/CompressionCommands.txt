Compression Commands :
        *Multiple files and folders are stored in a single file. which is compressed file or zip file.

sudo apt install zip    = to install zip package in the system.
zip -r filename.zip(new) filename(source)  = to create zip file.
unzip filename.zip   = unzipped the zip file

tar -cvzf filename.gz filename  = make tar zip file (c- create, v- verbose, z- zip, f- file)
tar -xvcf filename.tar.gz    = extract zip tar files
